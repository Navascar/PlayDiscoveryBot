# Telegram Quest Guide Bot (Бот-путівник)

Telegram бот-путівник для проведення квестів із керуванням маршрутами станцій через адмін-групу, 5-хвилинним таймером між станціями та перевіркою фінального ключового слова.

## 🛠 Налаштування та конфігурація

Створіть файл `.env` у коріновій директорії проєкту (скопіювавши з `.env.example`) та вкажіть свої дані:

```env
BOT_TOKEN=ваш_токен_бота
ADMIN_GROUP_ID=-1001234567890
STATION_COOLDOWN_SECONDS=300
DB_PATH=bot_data.db
```

- **BOT_TOKEN:** Токен Telegram-бота, отриманий від `@BotFather`.
- **ADMIN_GROUP_ID:** Telegram ID групи адміністраторів.
- **STATION_COOLDOWN_SECONDS:** Час виконання станції в секундах (за замовчуванням: `300` секунд / 5 хвилин).

## 📌 Команди для адмін групи

Всі команди управління квестом виконуються в групі адміністраторів:

- `/add_team (Номер)` — Додати новий номер групи (наприклад: `/add_team 1`).
- `/add_station (Номер) [Назва]` — Додати номер станції (наприклад: `/add_station 1` або `/add_station 1 Парк Шевченка`).
- `/clear_team (Номер)` — Видалити у власника номер групи (звільняє номер для інших учасників).
- `/clear_station (Номер)` — Видалити станцію з системи та маршрутів.
- `/name_station (Номер) (Назва)` — Назвати станцію або застосувати у відповідь на повідомлення з назвою.
- `/add_route (Номер команди)` — Застосовується **у відповідь (reply)** на повідомлення зі списком маршруту станцій для команди (наприклад, у відповідь на `1\n2\n3`).
- `/game_start` — Почати видавати маршрути та першу станцію всім учасникам, які заняли номери команд.
- `/final_word (Слово)` — Встановити фінальне ключове слово, яке учасники вказують після проходження всіх станцій.
- `/status` — Переглянути поточний статус квесту, створених команд та станцій.
- `/comands` — Надіслати список усіх доступних команд бота в адмін групу.

## 👥 Логіка для учасників (Приватні повідомлення)

1. При першому візиті у бот учасник вводить номер своєї команди.
2. Якщо номер вказаний вірно та не зайнятий, учасник закріплюється за цією командою. Одночасно зайняти одну команду декільком людям неможливо.
3. Після команди `/game_start` (або одразу після авторизації, якщо гра вже триває), бот присилає учасникові назву першої станції з кнопкою **«Виконано»** під полем вводу.
4. Натиснути кнопку **«Виконано»** можна лише після закінчення 5 хвилин. При передчасному натисканні бот показує таймер залишку часу.
5. Після проходження всіх станцій бот надсилає запит: `"Введіть фінальне повідомлення:"`.
6. Учасник вводить ключове слово. При вірному вводі бот вітає учасника та сповіщає адмін-групу.

## 🚀 Запуск бота

```bash
pip install -r requirements.txt
python main.py
```
